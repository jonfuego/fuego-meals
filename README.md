# fuego-meals

Static site for https://meals.fuegofam.com. Weekly low-carb, GLP-1-friendly meal plan built from the San Diego Vons, Ralphs, Stater Bros. and Sprouts Wednesday ads.

- `index.html`: the current week (what the site serves)
- `archive/`: every week's page, `meal-prep-thursday_weekly-plan_vN.html`

Deployed by Cloudflare Pages on every push to `main`. No build step.
